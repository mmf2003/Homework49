# React User Profile Testing

A React application built with Vite that demonstrates asynchronous API requests and component testing with Vitest and React Testing Library.

## Features

- Fetch user data from API
- Loading state
- Error handling
- User profile display
- API mocking in tests
- Testing loading, success and error states

## Technologies

- React
- Vite
- Vitest
- React Testing Library
- JSONPlaceholder API

## Installation

Install dependencies:

```bash
npm install
```

Run the application:

```bash
npm run dev
```

Run tests:

```bash
npm test
```

## Tests

The project includes tests for:

- Loading state
- Successful API response
- Failed API request
